C4.5 訊息增益比 (Gain Ratio) 計算機制

C4.5 算法克服了 ID3 偏好取值較多屬性的缺陷，採用訊息增益比 (Gain Ratio) 作為切分標準：

1. 訊息熵 Info(D) = - ∑ (p_i * log2(p_i))
2. 條件熵 Info_A(D) = ∑ (|D_j|/|D|) * Info(D_j)
3. 訊息增益 Gain(A) = Info(D) - Info_A(D)
4. 固有拆分 SplitInfo_A(D) = - ∑ (|D_j|/|D|) * log2(|D_j|/|D|)
5. 增益比 GainRatio(A) = Gain(A) / SplitInfo_A(D)

本模型各症狀屬性切分權重比：

  • 淋巴腺腫脹 (Swollen Nodes): GainRatio = 1.000 (首選根節點)
  • 發燒 (Fever): GainRatio = 0.863 (次級節點)
  • 喉嚨痛 (Sore Throat): GainRatio = 0.412
  • 充血 (Congestion): GainRatio = 0.305
